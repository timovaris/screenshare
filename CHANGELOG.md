# Changelog

## [0.1.0 Preview](https://github.com/timovaris/screenshare/releases/tag/v0.1.0-preview) - 2026-09-05

First public preview for Windows 11 x64.

- Native, resizable region selector and separate shareable output window.
- Windows Graphics Capture and D3D11 GPU capture, cropping, and rendering.
- Aspect-preserving output and a presentation cap of 30 FPS.
- 1280 x 720, 1920 x 1080, and half-screen presets.
- Monitor lock, cursor capture, always-on-top, and pause/resume controls.
- Automatic overlap pause and recovery, minimize/restore, and error status.
- Per-Monitor DPI Awareness v2 and physical-pixel region mapping.
- Original app icon, Windows version metadata, and About dialog.
- Portable ZIP packaging with license, documentation, and SHA-256 checksum.

### Known Limitations

Meeting-app compatibility, mixed-DPI configurations, device-loss recovery, and
performance still require broader manual validation. HDR tone mapping, settings
persistence, global hotkeys, and multiple regions are not implemented.
